# TaskFlow 🎯

TaskFlow — це мінімалістичний та швидкий веб-застосунок для управління завданнями, створений для організації особистих проєктів та підвищення продуктивності. Жодних зайвих відволікань, лише чистий інтерфейс та повний контроль над вашим часом.

🔗 **[Дивитися Live Demo](https://nicholas-nak.github.io/TaskFlow/)**

## ✨ Головні можливості

- **📊 Аналітичний дашборд:** Загальний огляд прогресу, автоматичний підрахунок активних, завершених, прострочених та пріоритетних завдань.
- **📁 Управління проєктами:** Створення, перейменування та видалення проєктів для логічного групування ваших завдань.
- **🔍 Живий пошук і фільтрація:** Миттєвий пошук завдань за назвою та розумне сортування (за алфавітом, пріоритетом, дедлайном або часом створення).
- **📅 Робота з датами:** Зручна навігація за категоріями: «Сьогодні», «Майбутні» та «Завершено».
- **💾 Локальне збереження:** Усі дані автоматично та надійно зберігаються у LocalStorage вашого браузера — нічого не зникне після оновлення сторінки.
- **🎨 Продуманий UI/UX:** Адаптивний інтерфейс, можливість згортання бічної панелі, зручні модальні вікна та плавні анімації.

## 🛠 Технологічний стек

Проєкт побудований на базових веб-технологіях з акцентом на модульну архітектуру :

- **HTML5 & CSS3:** Семантична верстка, CSS Grid / Flexbox, кастомні змінні.
- **Vanilla JavaScript:** ES6 модулі, класи (OOP), робота з DOM та подіями без використання важких фреймворків.
- **Webpack:** Збірка проєкту (Bundling), управління асетами та dev-сервер.
- **date-fns:** Легковажна бібліотека для форматування та порівняння дат.

## 🚀 Як запустити локально

1. **Склонуйте репозиторій:**
    ```bash
    git clone https://github.com/nicholas-nak/TaskFlow.git
    ```

2. **Перейдіть у папку з проєктом:**
    ```bash
    cd TaskFlow
    ```

3. **Встановіть залежності:**
    ```bash
    npm install
    ```

4. **Запустіть сервер для розробки:**
    ```bash
    npm start
    ```
   *(Застосунок автоматично відкриється у вашому браузері за адресою `http://localhost:8080`)*

5. **Збірка для продакшену:**
    ```bash
    npm run build
    ```
   *(Готові оптимізовані файли з'являться у папці `/dist`)*
